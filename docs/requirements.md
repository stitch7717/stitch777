# 医疗后台管理系统需求文档

## 一、项目概述

### 1.1 项目背景
随着医疗机构信息化建设的推进，需要一套完整的后台管理系统来支撑医院的日常运营、患者管理、医疗资源调配等核心业务。

### 1.2 项目目标
构建一个安全、高效、可扩展的医疗后台管理系统，实现医疗业务全流程数字化管理，提升医疗服务效率与质量。

### 1.3 目标用户
- 系统管理员
- 医生/护士
- 挂号/收费人员
- 药房/库房人员
- 财务人员
- 院长/管理层


## 二、功能模块划分

### 模块一：系统管理

| 子模块        | 功能说明                                    |
| ------------- | ------------------------------------------- |
| 用户管理      | 用户增删改查、账号启用/禁用、密码重置       |
| 角色管理      | 角色定义、角色权限分配                      |
| 权限管理      | 菜单权限、按钮权限、数据权限（按科室/按人） |
| 部门/科室管理 | 科室树维护、科室人员归属                    |
| 菜单管理      | 动态菜单配置、路由管理                      |
| 日志管理      | 登录日志、操作日志、异常日志                |
| 数据字典      | 枚举值维护（性别、学历、职称等）            |
| 系统参数      | 全局配置项（超时时间、编号规则等）          |

### 模块二：患者管理

| 子模块     | 功能说明                              |
| ---------- | ------------------------------------- |
| 患者档案   | 基本信息、身份证、联系方式、过敏史    |
| 就诊卡管理 | 发卡、挂失、补卡、余额查询            |
| 病历管理   | 电子病历（EMR）创建、修改、查看、归档 |
| 既往病史   | 既往病史、家族病史、手术史记录        |
| 患者标签   | 慢病标签、VIP标签、高风险标签         |
| 随访管理   | 随访计划、随访记录、提醒              |

### 模块三：挂号与预约

| 子模块   | 功能说明                          |
| -------- | --------------------------------- |
| 号源管理 | 排班设置、号源数量、专家号/普通号 |
| 预约挂号 | 线上/线下预约、取消、改约         |
| 排队叫号 | 候诊队列、叫号顺序、大屏显示      |
| 挂号收费 | 挂号费收取、退号退费              |
| 医生排班 | 周排班、临时调班、停诊管理        |

### 模块四：门诊管理

| 子模块   | 功能说明                         |
| -------- | -------------------------------- |
| 接诊管理 | 患者列表、叫号接诊、转诊         |
| 处方管理 | 西药处方、中药处方、处方审核     |
| 检查检验 | 开检查单、检验单、结果回传       |
| 诊断管理 | 主诊断、次诊断、ICD编码          |
| 门诊病历 | 主诉、现病史、体格检查、处理意见 |
| 收费结算 | 处方划价、收费、退费、发票打印   |

### 模块五：住院管理

| 子模块   | 功能说明                     |
| -------- | ---------------------------- |
| 床位管理 | 床位分配、床位状态、病区管理 |
| 入院登记 | 入院办理、押金收取、医保登记 |
| 医嘱管理 | 长期医嘱、临时医嘱、医嘱执行 |
| 护理管理 | 护理记录、体温单、生命体征   |
| 住院病历 | 入院记录、病程记录、出院小结 |
| 出院结算 | 费用汇总、医保报销、出院办理 |

### 模块六：药品与药房管理

| 子模块   | 功能说明                       |
| -------- | ------------------------------ |
| 药品目录 | 药品信息、规格、剂型、价格     |
| 库存管理 | 入库、出库、盘点、库存预警     |
| 药房发药 | 门诊发药、住院发药、退药       |
| 采购管理 | 采购计划、采购订单、供应商管理 |
| 效期管理 | 近效期预警、过期药品处理       |
| 特殊药品 | 麻精药品、毒麻药品专项管理     |

### 模块七：检查检验管理（LIS/PACS）

| 子模块   | 功能说明                     |
| -------- | ---------------------------- |
| 检查申请 | 医生开单、申请审核           |

| 危急值   | 危急值提醒、处理闭环         |

### 模块八：收费与财务管理

| 子模块   | 功能说明                     |
| -------- | ---------------------------- |
| 收费管理 | 门诊收费、住院收费、预交金   |

| 日结月结 | 收费员日结、财务对账         |
| 价格管理 | 诊疗项目价格、药品价格维护   |
| 医保结算 | 医保接口、报销比例、结算清单 |

### 模块九：公共卫生与健康管理

| 子模块     | 功能说明                     |
| ---------- | ---------------------------- |
| 健康档案   | 居民健康档案、慢病管理       |
| 疫苗接种   | 接种记录、疫苗库存、提醒     |

| 妇幼保健   | 孕产妇管理、儿童保健         |

### 模块十：统计报表

| 子模块     | 功能说明                         |
| ---------- | -------------------------------- |
| 门诊统计   | 门诊量、人次、科室分布           |
| 住院统计   | 住院人数、床位使用率、平均住院日 |
| 收入统计   | 收入构成、科室收入、医生绩效     |
| 药品统计   | 药品消耗、销售排行               |
| 患者分析   | 年龄分布、病种分布、地域分布     |
| 自定义报表 | 拖拽式报表配置、导出Excel/PDF    |

### 模块十一：消息与通知

| 子模块   | 功能说明                       |
| -------- | ------------------------------ |
| 站内消息 | 系统通知、待办提醒             |
| 短信通知 | 预约提醒、报告发布、随访提醒   |
| 公告管理 | 院内公告、科室公告             |
| 预警提醒 | 库存预警、效期预警、危急值提醒 |

| 子模块   | 功能说明                           |
| -------- | ---------------------------------- |
| 数据加密 | 敏感字段加密存储（身份证、手机号） |
| 访问控制 | IP白名单、登录限制、双因素认证     |
| 操作审计 | 关键操作留痕、可追溯               |
| 数据备份 | 定时备份、灾备恢复                 |
| 隐私保护 | 数据脱敏、权限最小化               |

## 五、核心业务流程示例

**门诊流程：**
挂号 → 候诊叫号 → 医生接诊 → 开处方/检查 → 收费 → 取药/检查 → 离院

**住院流程：**
门诊开住院单 → 入院登记 → 床位分配 → 医嘱执行 → 护理记录 → 出院结算 → 病历归档
